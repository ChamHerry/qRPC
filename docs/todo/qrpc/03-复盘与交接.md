## 6. 维护指南

### 6.1 常用操作

| 操作 | 命令/入口 | 说明 |
|---|---|---|
| 构建 | `cargo build --workspace` | 全 Rust workspace |
| 内核测试 | `cargo test -p qrpc-core` | 单测 + 集成 |
| 跨语言测试 | `just test-interop` | 6 组组合 |
| 性能 | `cargo bench -p qrpc-core` | criterion |
| 全量验证 | `just verify` | C-999 |
| 生成 stub | `protoc --qrpc_out=...` | protoc-gen-qrpc |

### 6.2 配置说明

| 配置 | 推荐值 | 注意事项 |
|---|---|---|
| 默认端口 | `7000` | 可配置（决议 D1） |
| 最大消息上限 | `4 MiB` | 可配置（决议 D5） |
| TLS | 强制 1.3 | 无明文模式 |

### 6.3 日志与排查

| 场景 | 查看位置 | 判断方法 |
|---|---|---|
| 调用失败 | STATUS 帧 / 绑定异常 | 状态码（docs/04 §7） |
| 取消未清理 | server handler 资源/任务计数 | T-016 矩阵 |
| 连接异常 | 连接级事件回调（QR_CONN_EV_*） | docs/05 §3.1 |

## 7. 已知限制（0.1）

| 限制 | 影响 | 后续建议 |
|---|---|---|
| 仅 quinn 后端 | 无 MsQuic 高吞吐 | NEXT-001（0.2） |
| 无 RDMA | 无近场超低延迟 | NEXT-002（2.0） |
| 无 datagram | 无带外低延迟通道 | NEXT-003（0.3） |
| 无 lb/服务发现/重试/健康检查/反射 | 生产功能不全 | NEXT-005 |
| 仅 3 语言 | 生态有限 | NEXT-006（0.3+） |
| C ABI 未冻结 | 不保证兼容 | NEXT-008（1.0） |
